设置

双击快捷键开始录入；ESC 取消。修改或恢复默认后点击保存。

Mac 游戏中可将鼠标移到屏幕顶部，在“窗口”菜单中退出全屏或返回游戏库。

Windows 游戏中可使用自定义快捷键切换全屏或返回游戏库。

独立游戏窗口，随时回到游戏库。入口与登录会话保存在本机。

游戏内外部 HTTPS 网页申请权限时，同意授权会自动标记为该游戏的衍生网页；你也可以在此手动添加或删除。

清理云游戏网页的本地缓存或会话数据。游戏列表、衍生网页与快捷键配置不会被删除。

清除网页缓存 清除云游戏页面的 HTTP 缓存、脚本缓存与离线缓存，解决加载异常或资源卡顿；保留登录状态与游戏列表。
清除登录与网站数据 清空所有云游戏网站的 Cookie、登录会话、本地存储和缓存，相当于重置登录态；游戏列表、衍生网页与快捷键会保留。
